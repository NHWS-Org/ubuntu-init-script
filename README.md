# ubuntu-init-script
Scripts useful to setup an ubuntu server

# Deployment istruction
```
bash <(curl -fsSL "https://raw.githubusercontent.com/napalmz/ubuntu-init-script/main/ubuntu-init-script.sh?$RANDOM")
```

Lo script genera anche alcune utility nella home dell'utente, incluse:
- upgrade.sh
- docker-prune.sh
- sysinfo.sh
- tailscale-up.sh
- dockcheck.sh
- docker-portainer-agent-update.sh
- docker-portainer-main.update.sh
